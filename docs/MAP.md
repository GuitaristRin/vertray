# vertray 正典

> 图可重画，来源不可追补。

本文定 vertray 的概念与契约。语义有变，随代码一同修订。调用方的具体样式、交互与品牌可自行决定，不因此成为全体的强制规范。

## Ⅰ · 何为 vertray 地图

一张 vertray 地图不是图像，而是**一组关于空间的可核验陈述**：某个建筑在这个位置，某扇门开在这一侧，从这条路到那扇门可以步行抵达。渲染只是把这组陈述画出来的一种表达。

由此推出三件事：

- 地图的正确性取决于**陈述与其依据的关系**，不取决于它像不像。
- 不知道的事必须以未知表达，不以省略、空白或默认值代替。
- 任何几何都能被追问「你凭什么这么说」，且必须答得出来。

## Ⅱ · 三层

| 层 | 内容 | 谁负责 |
|---|---|---|
| 事实层 | 几何、属性、来源、核验状态 | 数据与采集 |
| 表达层 | 图层、配色、标注层级、实线与虚线 | 引擎默认，宿主可调 |
| 产物层 | 分档 SVG、构建报告 | 生成器 |

事实层禁止出现无来源的几何。表达层可以自由，但不得改变事实层的可读性——把推断画成与实测相同的样式，等于篡改事实。

## Ⅲ · 来源与核验状态

每项数据至少携带：

| 字段 | 取值 | 作用 |
|---|---|---|
| `source` | 现场观察 / 用户说明 / 导览图 / 卫星图 / 公开数据集 | 依据的种类 |
| `checkedAt` | 日期 | 依据的时效 |
| `confidence` | 已核对 / 示意 / 待采集 | 可直接用于导航，还是仅作提示 |
| `scope` | 覆盖范围与未确认项 | 一句话说清它不是什么 |

`confidence` 不是程度副词，而是**能不能拿去做导览的分界**：只有「已核对」可以参与路径结论；「示意」只能显示，不能承诺；「待采集」不绘制。

## Ⅳ · 表达：实线与虚线

- **实线**：已核对。
- **虚线**：示意或推断，且必须可被读者识别为不确定。
- **不绘制**：完全未知。

三者不得互相顶替。用虚线画一条其实没去过的门，比不画更糟——它让未知看起来像已知。

## Ⅴ · 不变量

1. **可追溯。** 每条几何可回指来源与核验日期；无来源者不得以实线出现。
2. **配准稳定。** 画布坐标系确定后不得静默改变。改变配准是一次版本事件，须记录旧值、新值与迁移影响。
3. **可重复。** 同一输入生成同一产物；构建报告记录输入哈希与输出统计。
4. **离线自足。** 生成与运行不依赖网络、第三方瓦片服务或需注册的工具链。
5. **未知即未知。** 未核验的通行权限不等于允许；未确认的室内结构不等于不存在。
6. **许可可分离。** 事实层按来源分属 ODbL 与 Noncommercial，生成过程不得使其混同。
7. **产物不手改。** 分层 SVG 由生成器产出；需要不同表达时改表达层，不改产物。

## Ⅵ · 入口模型

地图上最常见的错误是把「建筑」与「建筑的入口」当成同一个点。vertray 的分工是：

- **建筑**是可被选中、被命名的区域，其几何是轮廓。
- **入口**是轮廓边界上的节点，带朝向、可到楼翼与通行条件。
- **接近点**是入口外最近的可通行道路位置，用于路线收口。

导航终点落到入口，不落到楼中心。楼中心只用于标注与拾取，不用于抵达。

入口同样受 Ⅲ 约束：门位未知时留空并标注「待采集」，不按建筑方位推一个「应该在此」。

## Ⅶ · ODbL 边界

事实层分两部分，边界是硬性的：

- `data/base/`：派生自 OpenStreetMap，依 ODbL 提供并署名。**不可另行限制，也不可主张保留所有权利。**
- `data/survey/`：实地所得，依本仓条款提供。

生成器可以读取两者，但不得把 `base/` 的几何抄写进 `survey/` 的文件以绕开 ODbL。产物（SVG）属于 Produced Work，随其来源保留署名。

详见 [data/README.md](../data/README.md)。

## Ⅷ · 失败模式

以下情形一旦出现，地图即失去可信度，且通常无法靠补数据挽回：

| 失败 | 表现 | 后果 |
|---|---|---|
| 推断当事实 | 虚线被画成实线，或未核验的门按对称补全 | 用户按图走错，且无法判断哪里错 |
| 空白当未知 | 未知处留白，被读成「没有」 | 把「没去过」误读成「没有门」 |
| 配准漂移 | 静默调整比例或偏移 | 全部历史实测同时失效 |
| 来源丢失 | 数据在迁移、格式化、合并中丢掉 `source` | 无法复核，也无法证明 |
| 许可混装 | 两类数据进同一文件 | 两套条款同时失效 |

## Ⅸ · 范围外

室内结构、实时人流、公车到站、充电桩状态，可以在同一模型上扩展，但不属于 v0 的承诺。扩入时须先有来源与核验方式，不得以「以后会有」为理由先画上去。
