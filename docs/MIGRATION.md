# 迁移记录

本文件记录从既有实现迁入本仓的内容与验收方式，供日后复核。迁移期间宿主仓 `portal-web` 的构建在替换前后各验证一次，均通过。

## 迁入内容

| 项 | 内容 | 验收 |
|---|---|---|
| 底图几何 | 用地、水系、路缘、道路、人行道、围墙、建筑轮廓、桥 | 390 条路径；配色 ⊆ 既有图 |
| 场地内线 | 跑道三条内缩椭圆、球场内缩边界 | 与既有实现同位置同色 |
| 标注 | 路名、图题、指北针、比例尺、来源署名 | 源图 9 个路名全部匹配 |
| 校外背景 | 105 个 OSM 地物，evenodd 裁到校园之外 | 与既有边界一致 |
| 采集器 | `tools/collector-android/`，Java 原样迁入 | 源码在手，Kotlin 化另计 |
| 宿主接回 | 三档 SVG 替换 `portal-web/public/assets/map/` | 构建通过；产物逐字节一致 |

## 验收手段

- **条数**：产物各层路径/标注数与既有构建报告对齐。
- **配色**：两版 SVG 的 fill/stroke 集合做差集，本仓不得出现既有图里没有的颜色。
- **渲染**：无头浏览器出 PNG 人工比对。
- **测试**：`pnpm test` 与 `pnpm typecheck` 必须通过。
- **可复现**：重跑构建得到与已提交产物逐字节相同的三张图。

## 回滚

每项一个独立提交，可按项回退。宿主仓只承接产物，不依赖本仓的构建时状态。
