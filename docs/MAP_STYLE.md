# 地图样式正典

> 直角丈量边缘，一屏一色。

本文件定 vertray 产物的视觉规则。实现见 `src/render/style.ts`、`src/render/model.ts`、`src/render/svg.ts`。

## Ⅰ · 来源

| 来源 | 取了什么 |
|---|---|
| [Kanesumi Design §Ⅲ/§Ⅳ](../../Ether/docs/KANESUMI_DESIGN.md) | 直角、贴边、单一强调色、纯色无渐变无阴影 |
| Win10 时代地图 | 中性三阶底、发丝线、内容优先、低视觉噪音 |

两者不冲突：Win10 地图提供**怎么把地物画得安静**，Kanesumi 提供**什么允许出现**。

## Ⅱ · 四条约束

1. **中性分层。** 底色、用地、开敞地、建筑、连接体是五级明暗，没有色相。深度靠亮度差，不靠投影。
2. **单一强调色。** 一屏只有一个 accent，换它即换掉全部强调表现。本图里 accent 只出现在「已核对的入口」——那是地图最该传达的信息。
3. **直角。** 无圆角、无圆点。所有点标记是方块，所有图形用 miter 连接，`rx` 一律不出现。
4. **无渐变、无阴影、无滤镜。** 标注的可读性靠描边光晕（`paint-order="stroke"`），不靠投影。

## Ⅲ · 色板

| token | 值 | 用途 |
|---|---|---|
| `outside` | `#EFEFEF` | 视口底，校园之外 |
| `land` | `#F8F8F8` | 校园用地 |
| `open` | `#F1F1F1` | 运动场等开敞地 |
| `building` | `#E3E3E3` | 建筑 |
| `link` | `#DDDDDD` | 楼栋连接体 |
| `gate` | `#3A3A3A` | 校门（深墨方块） |
| `ink` | `#161616` | 主标注 |
| `inkMuted` | `#666666` | 次标注 |
| `hairline` | `#D9D9D9` | 发丝线 |
| `accent` | `#009ADC` | 已核对入口；实例可覆盖 |

取值是按观感重定的中性阶梯，不是微软原始色值。

## Ⅳ · 可信度不用颜色区分

三种入口状态若各配一色，就破了「一屏一色」。所以用**形状与填充**区分：

| 状态 | 画法 |
|---|---|
| 已核对 | accent 实心方块 |
| 近似 | 空心中空方块，accent 描边 |
| 未核对 | 中性灰小方块 |
| 未知 | 不画 |

这样即使换 accent，语义也不丢。

## Ⅴ · 取景

视口 = 校园多边形外框 + 44 画布单位留白，**不输出登记画布里的空白带**。

配准不动，只改取景：所有几何仍在同一套画布坐标里，裁切只是 viewBox 位移。这对应 Kanesumi 的「贴边」——内容接触边缘，不留装饰性边框。

## Ⅵ · 不画什么

- **没有来源就不画。** 当前数据没有路网、水系、绿地，就不补；空白是诚实，装饰不是。
- 不为好看加圆角、渐变、投影、纹理。
- 不为了「填满」而放大标注或改变字号层级之外的尺寸。

## Ⅶ · 换色

实例的 `instance.json` 写 `accent`，构建时传入。产物里不会残留默认色——测试会检查这一点。
